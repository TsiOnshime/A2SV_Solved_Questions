# [Primes in a Range](https://www.geeksforgeeks.org/problems/find-prime-numbers-in-a-range4718/1)
## Medium
Given two integers l and r, find and return all prime numbers in the range [l, r] (inclusive).
Examples:
Input: l = 1, r = 10
Output: [2, 3, 5, 7]
Explanation:
The prime numbers between 1 and 10 are 2, 3, 5 and 7.
Input: l = 2, r = 5
Output: [2, 3, 5]
Explanation:
The prime numbers between 2 and 5 are 2, 3 and 5.
Constraints:1≤ l ≤ r ≤ 106
