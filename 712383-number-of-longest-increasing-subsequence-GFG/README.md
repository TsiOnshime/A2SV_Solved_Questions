# [Number of Longest Increasing Subsequence](https://www.geeksforgeeks.org/problems/number-of-longest-increasing-subsequence/1)
## Medium
Given an integer array&nbsp;arr, return the number of longest increasing subsequences.&nbsp;Note&nbsp;that the sequence has to be&nbsp;strictly&nbsp;increasing.
Example:
Input: arr = [1, 3, 5, 4, 7]
Output: 2
Explanation: The two longest increasing subsequences are [1, 3, 4, 7] and [1, 3, 5, 7].
Input: arr = [2, 2, 2, 2, 2]
Output: 5
Explanation: Each LIS has a Length of 1. 
Constraint:1&nbsp;≤&nbsp;n&nbsp;≤&nbsp;20001&nbsp;≤&nbsp;arr[i]&nbsp;≤&nbsp;105
